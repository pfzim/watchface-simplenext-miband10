# SimpleNext - Xiaomi MiBand 10 Watchface

Циферблат для смарт-часов Xiaomi Smart Band 10.
За основу взят циферблат 26_Simple.v3.face.zip.

| ![img1](preview_0.png) | ![img2](preview_aod.png) | ![img3](preview_1.png) | ![img4](preview_2.png) |
|:---:|:---:|:---:|:---:|
| Сердцебиение, калории, шаги | AOD | Только шаги | Всё плюс километраж |

Скачать готовый циферблат можно в разделе [Releases](https://github.com/pfzim/watchface-simplenext-miband10/releases)

Собрать из исходного проекта можно с помощью WatchfaceCompiler:
```
WatchfaceCompiler.exe build band10 path\to\SimpleNext_v3.1 SimpleNext_v3.1.face
```
